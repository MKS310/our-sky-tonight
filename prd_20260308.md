# PRD: Our Sky Tonight — Feature Updates

**Date:** 2026-03-08
**Project:** Our Sky Tonight (static astronomy dashboard, Neenah WI)
**Repo:** `our-sky-tonight`

---

## Summary

Five targeted updates to improve reliability, enrich daily content, and add new sections. All changes must maintain the terminal aesthetic, static-site architecture, and mobile-first layout.

---

## Feature 1: Fix GitHub Actions Workflow

**Priority:** Critical — blocks all daily updates

**Problem:** The workflow is broken. Stale action versions and possible credential conflicts prevent automated daily builds from deploying.

**Requirements:**
- Update `actions/checkout` to `@v4`
- Update `JamesIves/github-pages-deploy-action` to current stable `@v4` tag format
- Resolve any `persist-credentials` conflicts with the deploy step
- Align cron schedule with documented Mon–Fri intent (or confirm daily is desired)
- Verify push trigger and scheduled trigger both work
- Confirm `dist/` deploys correctly to `gh-pages` branch

**Files:** `.github/workflows/build.yml`

---

## Feature 2: Real Daily Horoscopes

**Priority:** High — current implementation is placeholder/broken

**Problem:** `fetchHoroscopes()` in `index.js` returns hardcoded text for all 12 signs. Section header says "Work in Progress."

**Requirements:**
- Replace hardcoded values with a live daily horoscope source
- Preferred source: `aztro` API (free, no key, per-sign via POST) or a reliable per-sign RSS feed
- Fallback: curated 12-sign × 30-day rotating content keyed by day-of-month
- Remove "Work in Progress" from section title in `templates.js`
- Maintain existing 12-card grid layout
- Follow existing error fallback pattern (resolve with defaults, never reject)

**Files:** `index.js` (`fetchHoroscopes()`), `templates.js` (`horoscopesSection()`)

---

## Feature 3: Stoic Quote of the Day

**Priority:** Medium

**Problem:** Only one quote source exists (ZenQuotes). A Stoic-focused second source adds depth and variety.

**Requirements:**
- Add `fetchStoicQuote()` in `index.js`
  - Preferred: `stoic-quotes.com/api/quotes/random` (free, no key)
  - Fallback: curated rotating list of 30+ quotes (Marcus Aurelius, Epictetus, Seneca) keyed by day-of-year
- Add `stoicQuoteSection(quote)` in `templates.js`
  - Label: "Stoic Thought of the Day"
  - Use `--accent-magenta` or `--accent-purple` accent color
  - Visually distinct from ZenQuotes box
- Position: directly after the existing ZenQuotes header section
- Wire into `Promise.all` with proper results destructuring

**Files:** `index.js`, `templates.js`

---

## Feature 4: Astrophotography Tip of the Day

**Priority:** Medium

**Problem:** No section exists for astrophotography guidance, which is a natural fit for the audience.

**Requirements:**
- Add `getAstroPhotographyTip()` in `index.js` — selects from curated tip set by day-of-year (same pattern as `getDailyAstronomyJoke()`)
- Curate 20–30 tips covering: camera settings (ISO/aperture/shutter), equipment (mounts, dew heaters), post-processing (stacking, noise reduction), seasonal target selection, beginner mistakes
- Add `astrophotographyTipsSection(tip)` in `templates.js`
  - Label: "Astrophotography Tip of the Day"
  - Include "Learn More" link (e.g. `astrobackyard.com`)
  - Style with `--accent-cyan` accent
- Position: after meteor showers section, before APOD
- No external API required — pure static rotating content

**Files:** `index.js`, `templates.js`

---

## Feature 5: UFO Files Corner Card

**Priority:** Low/Fun

**Problem:** No "weird/fun" section beyond horoscopes and jokes.

**Requirements:**
- Add `getDailyUFOImage()` in `index.js` — rotates through `images/ufo/` by day-of-year (same pattern as `getGalleryImages()`)
- Add 5–10 public domain / declassified UFO images to `images/ufo/`
- Add `ufoFilesSection(image)` in `templates.js`
  - Label: "The X-Files Corner" (or similar)
  - Rotating UFO image display
  - Curated links list to public document archives:
    - FBI Vault (UFO section)
    - NARA UFO records
    - CIA FOIA Reading Room
    - Project Blue Book Archive (`bluebookarchive.org`)
    - AARO (`aaro.mil`)
    - The Black Vault (`theblackvault.com`)
  - Style with `--accent-magenta` accent
- Position: immediately after horoscopes section

**Files:** `index.js`, `templates.js`, `images/ufo/` (new directory)

---

## Implementation Constraints

- All new fetches added to `Promise.all` in `index.js` with correct results destructuring offset
- All new sections wired into `document()` function signature in `templates.js`
- Error fallbacks on all network calls — resolve with defaults, never reject
- Static rotating content uses day-of-year pattern already established for astronomy jokes
- Terminal aesthetic preserved: `info-box` component, monospace for data labels, existing CSS variables
- No new dependencies beyond what's already in `package.json`

---

## Suggested Implementation Order

1. GitHub Actions fix (unblocks everything else)
2. Real horoscopes (highest user-visible impact)
3. Stoic quotes (quick win, low complexity)
4. Astrophotography tips (static content, no API risk)
5. UFO Files card (fun, lowest priority)
